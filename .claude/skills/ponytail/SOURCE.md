# Source

The skills `ponytail`, `ponytail-review`, `ponytail-audit` and `ponytail-debt` are copied unchanged from
<https://github.com/DietrichGebert/ponytail> (`skills/`), commit `09c434ab73ca43761c5d8b0c5d341926c2fba710`, MIT
licence (`LICENSE` in this folder). Added to Graphyne at the owner's request on 2026-10-28 (the same copy as in the WeaveScript repo).

Only the skill files were taken. The project's plugin hooks (session and prompt hooks, the "band" board, its cost
ledger in `~/.config/ponytail/` and optional webhook) are not installed, nor `ponytail-gain` and `ponytail-help`,
which describe those plugin features. To update, copy the four `SKILL.md` files from a newer commit and change the
commit above.
